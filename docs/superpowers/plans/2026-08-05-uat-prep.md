**Goal:** Config privacy (status-only), supplier-Excel/views.json upload+download in Settings, a first-class Key Insights panel, dark+gold well-fitted PPT, distinct chart palette with data labels, and a contained crosstab table.

**Architecture:** Server work stays in `dashboard.py` (strict config mask, `/api/files`, two upload routes, catfile download) with a small helper in `config_store.py`. `ppt_export.py`'s visual layer is rewritten around theme constants and a fixed layout grid (data source unchanged). `index.html` gets an Edit-mode connection section, a Data-files section, the Key Insights panel, a shared 12-color palette + chartjs-plugin-datalabels, and a scroll-contained table.

**Tech Stack:** Python 3.14 stdlib + python-pptx (installed) + openpyxl (already required by refine pipeline); vanilla JS + Chart.js 4 + chartjs-plugin-datalabels (CDN) + html2canvas.

## Global Constraints

- `GET /api/config` must NOT return raw `hostname`, `client_id`, or `client_secret` — only `{configured, host_hint, has_secret, schedule}`. `host_hint` = first 2 chars + `…` + last dot-suffix (e.g. `ap….onetrust.com`), `""` when unset.
- Upload routes write ONLY the two fixed filenames (`Supplier_Category_List.xlsx`, `views.json`) anchored to HERE — client never supplies a path. Validation: xlsx body starts with `PK`, ≤10 MB; views body parses as JSON with a `views` list, ≤2 MB. Atomic write (temp + `os.replace`).
- `views.json` is NOT downloadable. `Supplier_Category_List.xlsx` IS (`GET /api/catfile`, attachment; 404 JSON when absent).
- `.gitignore` must gain `Supplier_Category_List.xlsx`.
- PPT stays native/editable objects; data still from `build_payload`. Theme: slide bg `#1b1a19`, gold `#E8C810`, cream `#F3F2F1`, muted `#C8C6C4`, fills `#252423`/`#2F2E2D`. All shapes fit the 13.333×7.5in slide regions; >8 domains → top 7 + "Other (K)" table row.
- Shared chart palette (order): `#E8C810 #4FC3F7 #F0736A #34D399 #CE93D8 #FFB74D #90CAF9 #F48FB1 #AED581 #FFD54F #4DD0E1 #BCAAA4`; `(blank)`/Uncategorized always `#797775`.
- Server binds 127.0.0.1; bodies never logged; secret never sent to browser/DOM; tests need no network/threads/sockets; existing 50 tests stay green except those that assert the OLD /api/config shape (update those).
- Zone switching stays client-side; all existing exports/copy keep working.

```python
import os, tempfile

CAT_FILE = str(HERE / "Supplier_Category_List.xlsx")   # was bare filename


def strict_mask(cfg):
    return {"configured": is_configured(cfg),
            "host_hint": host_hint(cfg.get("hostname")),
            "has_secret": bool((cfg.get("client_secret") or "").strip()),
            "schedule": dict(cfg.get("schedule") or {})}


def _count_views():
    try:
        data = json.loads(Path(VIEWS_FILE).read_text(encoding="utf-8"))
        return len(data.get("views", []))
    except Exception:
        return None


def _count_suppliers():
    try:
        from openpyxl import load_workbook
        wb = load_workbook(CAT_FILE, read_only=True)
        n = max(0, (wb.active.max_row or 1) - 1)
        wb.close()
        return n
    except Exception:
        return None


def files_status():
    cat_present = Path(CAT_FILE).exists()
    views_present = Path(VIEWS_FILE).exists()
    return {"catfile": {"present": cat_present,
                        "suppliers": _count_suppliers() if cat_present else None},
            "views": {"present": views_present,
                      "view_count": _count_views() if views_present else None}}


def _atomic_write(target, data):
    d = os.path.dirname(str(target)) or "."
    fd, tmp = tempfile.mkstemp(dir=d, suffix=".tmp")
    try:
        with os.fdopen(fd, "wb") as f:
            f.write(data)
        os.replace(tmp, str(target))
    except Exception:
        try:
            os.unlink(tmp)
        except OSError:
            pass
        raise
```

```python
def _series_color(idx, cat=None):

def _fit_domains(doms, limit=8):
    if len(doms) <= limit:
```
